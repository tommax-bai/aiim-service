# apps/gateway — 执行端（微信协议网关）

薄。企微协议 HTTP 客户端 + webhook 入站归一化为标准入站事件 + 实例连接/登录态维持。**不做决策**。

- 出站：调 `add_*` / `send_*` / 群 / 朋友圈 等原子操作；即时本地校验（回执 ok/err、被限流、被撤回），**如实回报，绝不假成功**。
- 入站：接收协议 webhook（新消息 11010 / 好友变更 2131 / 好友申请 2132 / 群 / 朋友圈 / 掉线 …），`appinfo` 去重，归一化为 `packages/contracts` 的标准入站事件。
- 补漏：`push_sync_msg` 补拉、心跳自愈、`seq/version` 游标增量同步。
- 拟人抖动落地：决策端给中心值，这里叠 lognormal 抖动、保下限、断连兜底。

I/O 密集、可独立扩缩容。养号/IP/设备关切落在协议服务商实例层（`set_proxy` 配代理）+ 决策端风控。
