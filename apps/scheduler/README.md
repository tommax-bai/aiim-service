# apps/scheduler — 运营心跳调度器（主动运营驱动）

时间/状态驱动运营的命令式触发器（对应 AIDCP 的 content-scheduler）。独立进程、每分钟心跳。

- 遍历在线账号，按**闸序**判定：排期启用 ∧ 活跃时段格 ∧ 命中错峰分钟 ∧ 未达日上限 ∧ 风控 normal ∧ 过风控闸。
- **错峰**：`hash(accountId + 本地日期 + 动作) % 60`（纯函数、逐日变、账号间错开）。
- **幂等 + 重入护栏**：`(账号,动作,时间格)` 不重复触发；上轮未完跳过本轮。
- **fail-closed**：未配即不自动；**自动时窗 ⊆ 活跃时段**（休眠格绝不主动）。
- 产出运营任务（`followup.needed` / `moments.needed` / `group.sop.needed` / `nurture.needed`）注入下游统一管道。

驱动源：SOP 定时跟进、静默召回、朋友圈排期、群日历、养号任务。主动高风险动作（群发/发圈/批量加友）默认走人审提议。
